# Flask Full CRUD API — Event Management

A simple RESTful API built with Flask for managing events. Supports creating, updating, and deleting events using an in-memory list (no database) to simulate persistence.

## Purpose

This API demonstrates full CRUD (Create, Read, Update, Delete) operations using Flask, `request.get_json()` for handling incoming JSON, and `jsonify()` for structured JSON responses with appropriate HTTP status codes.

## Data Model

Each event is represented by an `Event` object with:
- `id` (int) — unique identifier, generated by the server
- `title` (string) — the event's name

## Routes

### `POST /events`
Creates a new event.

**Request body:**
```json
{ "title": "Hackathon" }
```

**Response (201 Created):**
```json
{ "id": 3, "title": "Hackathon" }
```

### `PATCH /events/<id>`
Updates the title of an existing event.

**Request body:**
```json
{ "title": "Hackathon 2025" }
```

**Response (200 OK):**
```json
{ "id": 3, "title": "Hackathon 2025" }
```

**Response if not found (404 Not Found):**
```json
{ "error": "Event not found" }
```

### `DELETE /events/<id>`
Removes an event from the list.

**Response (200 OK):**
```json
{ "message": "Event deleted successfully" }
```

**Response if not found (404 Not Found):**
```json
{ "error": "Event not found" }
```

## Running Locally

```bash
python3 -m venv venv
source venv/bin/activate
pip install flask
python3 app.py
```

Server runs at `http://127.0.0.1:5000`.

## Example Requests (curl)

```bash
# Create an event
curl -X POST http://127.0.0.1:5000/events \
  -H "Content-Type: application/json" \
  -d '{"title": "Hackathon"}'

# Update an event's title
curl -X PATCH http://127.0.0.1:5000/events/1 \
  -H "Content-Type: application/json" \
  -d '{"title": "Updated Meetup"}'

# Delete an event
curl -X DELETE http://127.0.0.1:5000/events/2
```
